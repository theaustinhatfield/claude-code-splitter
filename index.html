Claude Code Splitter is a universal orchestrator. Install your preferred agents first.

Aider pip install aider-chat
GitHub CLI brew install gh

Enable Infinity Mode

Deploy the orchestration logic. This adds a modular script and secures your environment with a tool whitelist.

One-Line Setup curl -sSL https://raw.githubusercontent.com/theaustinhatfield/claude-code-splitter/main/install.sh | bash

Launch Your Swarm

Navigate to any codebase and run your swarm command. Mix and match any supported agents.

Infinity Command $ claude4
Mixed Swarm $ claude2 aider2 gh1
  • Recursion Protection: Smart detection prevents accidental nested swarms.
  • Cybersecurity Hygiene: Strict tool whitelists verify every command.
  • Infinite Spawning: Call any count like claude12 (Safety gate at 20+).
  • Diagnostics: Robust logging to ~/.claude-code-splitter.log.

Move panes with mouse or Ctrl+B + Arrows. Drag borders to resize. Zoom with Ctrl+B + Z. Set a per-agent title with todo "fix tests".
